macOS warning / quarantine
Verify the Router VPN package/binary checksum first. Then use System Settings → Privacy & Security → Open Anyway. For a verified extracted Router VPN folder only:
xattr -dr com.apple.quarantine /path/to/router-vpn
Do not remove quarantine from your whole Downloads folder or unrelated files.



AI assistant
Privacy-first status: provider credentials are not stored in router profiles or exported bundles. A provider-backed assistant will stay optional and local-controller-only. Until that encrypted/0600 provider configuration API is implemented and tested, this page does not ask for or transmit API keys.
The intended assistant context is a redacted Router VPN support snapshot: current mode availability/reasons, selected node metadata, DNS benchmark results, setup/docs version and non-secret health state. Private keys, router API tokens, SSH passwords and generated tunnel secrets must never be sent as model context.
