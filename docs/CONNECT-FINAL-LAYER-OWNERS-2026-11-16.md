# CONNECT final Start Layer ownership

This unit retains the original final SS2022/UoT-v2 member when an ordered
CONNECT path selects AES-256-GCM or AES-256-GCM plus XOR whitening. It extends the
schema-4 Server compiler and the concrete native final-owner union. The public
Android, Apple and desktop admission changes remain separate consumer units.
The imported HTTP/HTTPS CONNECT member still requires Start Layer Off.

The shared compiler admits only the final layer's matching concrete closure:
ordinary SS for Off/AES and the authenticated whitening outbound for AES plus
XOR. The original final source, key, paired identity, predecessor and separately
captured UoT-v2 service remain mandatory. Service derivation runs exactly once
when constructing the policy and again on each fresh Server-member read; an
inline `udp_over_tcp` object does not replace that service authority.

Native capture retains an exclusive original SS or whitening final, its exact
registered manager slot, concrete method/key/dialer/server, UoT client pointer,
version and dialer. Local and separately constructed Server captures use these
same checks. Replacing an equal-looking object does not transfer authority.
The authenticated-stream retirement receipt from the previously published
whitening prerequisite grants cleanup acknowledgement only. The original
operation errors and unrelated cipher-close errors remain visible; a failed
close can still be retried.

## Validation and its limits

The exact final shared source passed 89 records under `-race`: 25 complete
source/preparation cases, 19 original-service positive/negative records,
3 repeated-fresh-closure records, 9 Compare/retained-restoration records, and
33 adjacent existing CONNECT records. The new cases cover HTTP and HTTPS,
3/4/8-node sources, independent AES/AES-plus-XOR finals, original final
credentials/detours/UoT, Local and Server winners, and restored choices without
repeating comparison. Service node/source/key/version, missing service,
changed source key, inline UoT, unknown layer and wrong cipher are refused.
The existing runtime fixture provides the explicitly simulated native boundary;
these shared tests do not establish encrypted native forwarding.

Compilation took 65.125 seconds under the existing 300-second bound. Each
shared root retained its 90-second Go-test and 120-second process bounds. The
Compare/restore root took 85.277 seconds; its individual startup and restoration
contexts remained 20 seconds. No deadline was increased.

`50231eaff98ccc31b5cbd247a721c16e97fe5ec1` sources. All 70 real test records and both separately compiled causal controls
passed. The six baseline package durations were 1.863, 1.054, 46.958, 4.618,
22.333 and 2.823 seconds. Omitting the concrete key comparison or original

have separate socket-level witnesses. This is not installed-kernel, device or
