# Typed SOCKS desktop child adoption

This increment connects the schema-3 desktop preparation to the native child
coordinators on Linux, Windows and macOS. The child captures the original SOCKS
source, association owner, private option registry and preparation before native
Box construction. It cannot enter through the Local SOCKS, paired or CONNECT
source family. The imported proxy and negotiated UDP relay gain no direct host
permission; the original packet entry remains the physical scope.

Each platform prepares and activates the same sealed physical policy. Linux
retains its original parent admission, physical cover and source cleanup. Windows
retains the inherited journal and physical transaction. macOS retains one
exclusive policy together with the inherited process capture, original workspace,
utun preparation and source cleanup owner. The application gate remains closed
until the execution controller proves its selected path.

The child publishes distinct SOCKS adoption and readiness records, tied to the
original preparation, transfer, selected native identity, selection epoch,
reader, interface, MTU and selected proof. Last restoration retains the original
winner and common endpoint, performs fresh discovery and enters the saved-choice
proof factory. It cannot rerun Compare or use an ordinary Last publisher. The
existing physical MTU transaction now dispatches the original schema-3 policy;
the execution engine still owns the paused proof, replacement reader and resumed
selected path.

## Required component evidence

The mandatory shipping gate runs on each matching desktop host, before packaging.
It requires 55 exact records on Linux and Windows and 82 on macOS. These include
actual unstarted Box construction with the original SOCKS and paired SS factories,
changed graph rejection, target binding, private command replay, distinct adoption
and heartbeat publication, saved winner/endpoint, retained failed cleanup and a
late constructor after cancellation. Darwin adds inherited control, exclusive
policy, early Stop and stale private mailbox checks.

The native TUN and the child proof/installed-parent observations are explicit
component doubles. The source compilers, native option registries, Box, private
files, command dispatch and original child retirement logic execute. This gate
does not establish an installed tunnel, kernel permit, encrypted end-to-end
route, or physical device acceptance.

The baseline and mutation phases each preserve the original 120-second test
deadline and 600-second compiler/process deadline. Each phase joins two serial
processes under its separate 1200-second parent bound. Race is enabled on the
shipping hosts supported by the pinned toolchain; Windows ARM64 retains the
existing toolchain exception. Two compiled controls must fail at their intended
witnesses when schema-3 command dispatch is disabled and when readiness stops
rejecting an invalid selected proof. Original prepared source bytes must remain
unchanged after each overlay.

On Linux amd64, the exact final source passed all 10 roots and 55 required
records under Go 1.26.3 with `-race`. Both compiled causal controls failed at
their intended witnesses. A final rerun used the strengthened event parser,
which additionally refuses a parent test completing before its children and
output arriving after its test completion. The gate's seven adversarial runner
checks passed.

The existing SOCKS construction gate also passed its two roots, 20 records and
copied-owner causal control. Existing paired and CONNECT command, runtime and
saved-choice regressions passed all 10 selected roots and 54 records in 31.526
seconds. The construction gate's seven runner checks passed unchanged.

`1ac1a339cb1223e9c70eae14c44411c75033c02d` and Xray
`50231eaff98ccc31b5cbd247a721c16e97fe5ec1`. All 20 changed native templates

Windows and Darwin execution require their mandatory matching hosted runners;

## Remaining public adoption

The public desktop profile/Connect controller, saved session and MTU restart
adapters still need their distinct schema-3 branch. Installed encrypted acceptance
must exercise that complete path. These child components do not finish the
historical requirement set or expand the exact three-member Server/Compare
topology. Longer Local SOCKS remains a separate supported source family.
