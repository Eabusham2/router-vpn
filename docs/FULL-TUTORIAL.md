# Router VPN — start here

Use only **`router-vpn.zip`**. It contains the router stack, desktop clients, source, iOS Xcode project, mode list, and this full tutorial. The router endpoint is selected/imported at runtime; it is not compiled into the app.

## 1. Install on the ASUS AI Board with Portainer

1. Open the ASUS router page.
2. Open **AI Board → Portainer**.
3. In Portainer open **Stacks → Add stack**.
4. Name it `router-vpn`.
5. Open `server/portainer-compose.yaml` from this ZIP, copy all of it into Portainer, then press **Deploy the stack**.
6. Open the `router-vpn-init` container, choose **Logs**, and copy the generated setup token and bundle location.
7. Keep Portainer, AdGuard administration, SSH, the controller API, and SOCKS5 blocked from WAN.

## 2. ASUS WAN rules

Reserve the AI Board LAN address first. Forward only the transport ports generated by the installer to that address. The default generated set is:

- TCP `443` — REALITY/Vision
- UDP `443` — QUIC transport when enabled
- UDP `51820` — raw WireGuard
- UDP `51821` — AmneziaWG 2
- UDP `8443` — Hysteria2
- TCP/UDP `8388` — Shadowsocks when enabled

For IPv6, create matching inbound firewall allowances to the AI Board global IPv6 address. Do not expose TCP `1080`, Portainer, AdGuard admin, SSH, or the router-agent API.

## 3. Get the private client bundle

From a home-LAN computer, download the generated `router-vpn-client-bundle.zip` from the location printed in the init logs. It contains this router's private client keys and `router-vpn-bundle.json`. Do not share it.

## 4. Install the desktop client

### macOS

Unzip `router-vpn.zip`, open Terminal in the extracted folder, then run:

```bash
chmod +x client/install-macos.sh
sudo ./client/install-macos.sh
```

Launch:

```bash
sudo /opt/router-vpn-client/router-vpn-client
```

Open `http://127.0.0.1:8788`, import `router-vpn-bundle.json`, and enter your router's current public IPv4, global IPv6, or hostname. No backend is hardcoded.

### Windows

Open PowerShell as Administrator in the extracted folder:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\client\install-windows.ps1
```

Start Router VPN from the installed folder, open `http://127.0.0.1:8788`, and import the router bundle.

### Linux

```bash
chmod +x client/install-linux.sh
sudo ./client/install-linux.sh
sudo /opt/router-vpn-client/router-vpn-client
```

Then open `http://127.0.0.1:8788` and import the bundle.

## 5. Use it away from home

1. Leave it **Off** while at home.
2. Away from home, open the client UI.
3. Select the saved home router.
4. Choose **AUTO** for normal use, or choose a mode manually.
5. The recommended stealth profile is **VLESS + REALITY + Vision + uTLS**.
6. Enable **DAITA** only when the extra traffic is acceptable.
7. Enable **Jumbo** only on compatible Linux/GSO paths; ordinary internet links still use path-sized packets.
8. Enable **SOCKS5** for app-only proxying; leave it off for a full-device VPN.

## 6. SOCKS5

The SOCKS5 service is private and reachable only through the VPN. After the VPN connects, use the address shown in the imported router profile, normally:

```text
10.77.0.1:1080
```

Use the generated SOCKS username/password. Never forward TCP `1080` from WAN.

## 7. Port forwarding through the tunnel

In the client UI choose:

- TCP, UDP, or both
- one external port or a range
- destination port
- protected DMZ only for one dedicated tunnel peer

Protected DMZ excludes router administration, SSH, Portainer, AdGuard administration, SOCKS5, controller, and VPN listener ports.

## 8. Modes

See `docs/MODES.md`. AUTO starts with raw WireGuard and escalates until a health check succeeds. The final **ALL** mode tries the complete compatible TLS chain first and falls back to the complete QUIC chain.

## 9. iPhone/iPad

Open `ios/RouterVPN/project.yml` with XcodeGen/Xcode. Select your Apple team and enable the Network Extension entitlement. Build to your device. A distributable IPA cannot be included without your Apple signing certificate and entitlement approval.

## 10. Important status

Raw WireGuard, AmneziaWG 2, REALITY/Vision, Hysteria2, Shadowsocks, SOCKS5, runtime router profiles, IPv4/IPv6 routing, AdGuard DNS, and forwarding controls are wired into the package. Rosenpass, V2Ray-plugin, XHTTP/FinalMask, Naive, and the MAX/ALL chains still require their upstream binaries and generated profiles on the target router and must be tested on your exact AI Board before being treated as production-ready.
