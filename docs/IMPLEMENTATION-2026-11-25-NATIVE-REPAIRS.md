# November 25 native client and Setup Center repairs

## Product behavior

- **iOS multihop editor.** Selecting an imported Shadowsocks exit retains the paired entry identity and order. Its entry-transport picker can choose WireGuard, Fast or Strong only from that control's actual original files; AWG additionally requires the original WireGuard pairing asset. The map editor retains the entry for Home DNS and the imported public exit. [Reconciled UI requirements](CURRENT-REQUIREMENTS.md)
- **Verified onboarding.** The guide can restart from step one when browser storage is corrupt or unavailable. Restart discards pending checks. When two checks overlap, only the newest request can update its result. Browsers with checks saved before response validation repeat verification once and retain their Full Guide step. Setup Center distinguishes zero observed peers, missing peer coverage and an unknown deployed revision.
- **Candidate measurement.** Desktop skips duplicate prefix members before reading their private files. Suffix collisions retain the original execution-eligibility rule, and independent sources are checked after file capture. Launch input can be reused only after graph ownership, mutable members, physical path, DNS, projection and digest checks. Raw and desktop physical graphs retain separate inputs.
- **Confirmed mobile selection.** iOS Connect retains the node the user tapped across the asynchronous admission boundary. A failed node selection cannot connect the previously selected external node or display a success message. Android's saved lowest-latency selection likewise retains a failed-save error. Independent profile actions occupy independent SwiftUI Form rows.
- **Onboarding request ownership.** Restart retires pending verification results. Run all checks reserves each check before sending its first request; a later individual retry owns only its own check. A superseded batch cannot enqueue a stale request or overwrite a newer success, failure or status message.
- **Download shutdown.** Closing the package manager closes admission before joining retained deliveries, so another retained job cannot admit a new stream while shutdown waits on an existing writer. The original READY-based retention deadline remains unchanged.
- **AmneziaWG imported exits.** The shared schema-8 source and all native editors now preserve a paired WireGuard, AWG2 Fast or AWG2 Strong entry through Local imported Shadowsocks 2022 exits, saved profiles, Last restoration and public candidate insertion. Fast and Strong require their exact independent raw asset and mode. This source extension is qualified for release only by the mandatory encrypted native cases described below.
- **Paired entry Start Layer.** The same Local routes preserve the paired entry's Off, AES-256-GCM or AES-256-GCM + XOR whitening selection across Windows, macOS, Linux, Android and iOS. Each imported interior and final remains Off. Named and Last captures bind the original WG identity, selected AWG asset where applicable and separate outer-layer asset in order; candidates cannot reuse those credentials or endpoints.
- **macOS public-exit transport.** The shipping candidate transport accepts the exact five-field external-final draft envelope, binds it to the selected first node and retains every original source token. Previously the editor's valid existing WireGuard draft was rejected before dispatch because the transport allowed only four fields and required the last node as control.
- **Longer Server route provisioning.** The operator now accepts the existing schema-6 compiler's complete suffix, up to 95 members, and preserves each paired Shadowsocks stream's independent source identity. The offline router-agent checker assigns packet credentials only to actual packet members. These repairs keep a valid longer route from being rejected before its native lease can run.

## Native follow-up repairs

The `9cda43e30` release run exposed two additional failures. The Windows Xray bootstrap reached its 90-second aggregate limit during the sixth case's expected post-retirement refusal. Four earlier authenticated transfers had each waited about five seconds for cold REALITY detection. Commit `86e0272f4` uses the existing pinned detector observer at startup, with the original source inventory, race flags, child process/configuration checks and Windows compiler ownership. It retains all nine traffic cases and the 90-second limit and records each stage's elapsed time. Fifty ordinary source-authority, phase, scoped-reference and dependency tests passed. A hosted Windows rerun must establish the complete matrix's timing.

The Naive HTTP/2 native traffic test crashed during stream startup in its owner-close case. Source review identified request-header storage passed through integer addresses without pinning. Commit `67bac88cf` pins the enclosing header array, record backing and each NUL-terminated key/value before address conversion, then unpins after the native call returns. This follows the call-scoped storage lifetime in the pinned module's Cgo wrapper and leaves engine and stream shutdown behavior intact. All 31 existing checks passed, including the patched Go client race suite and ten ownership controls. The original native HTTP/2 traffic job remains mandatory on the release commit.

## Remaining acceptance

The ordered external-final source covers Local routes of 3–96 members with a paired WireGuard, AWG2 Fast or AWG2 Strong entry, its selected Off/AES/AES+XOR Start Layer, and literal-address imported Shadowsocks 2022 interiors and exit with Start Layer Off. Its six added AWG and eleven added entry-layer encrypted cases passed locally; complete fresh hosted amd64 and ARM64 packaging remains mandatory. Other imported protocols, hostname/private interiors, layers on the imported members, and Server or Compare execution remain outside this external-final family. The first packet prefix retains the distinct Router TCP measurement; authenticated public candidate challenges begin after an imported interior. These are implementation boundaries, not canceled requirements. [Ordered external exits and their verification](IMPLEMENTATION-2026-11-25-EXTERNAL-FINAL-AND-SERVER-RESPONSES.md)

The resulting commit requires hosted native compilation and encrypted-path checks, matching client packages and checksums, ARM64 images, and generated production Compose. Installed-device rendering, iOS signing and provisioning, off-LAN routing and DNS, kill-switch and network transitions, and private deployment still need direct evidence.
