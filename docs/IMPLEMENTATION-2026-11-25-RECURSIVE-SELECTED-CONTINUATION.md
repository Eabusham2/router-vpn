# Recursive selected-hop continuation and integration repairs

This continuation follows the [selected draft insertion record](IMPLEMENTATION-2026-11-25-SELECTED-DRAFT-INSERTION.md)
and the [reconciled requirements](REQUIREMENTS-RECONCILED.md). It removes the
single-private-intermediate restriction from the qualified Compare-selected
Local response family, connects the following measurement to the inserted row,
and repairs two independently reproduced product defects. Implementation,
controlled executable checks, hosted native qualification, and installed
acceptance remain separate evidence.

## Repeated measurements through the retained route

The selected response family retains its paired WireGuard entry, independently
imported literal-address Shadowsocks 2022 first stream, paired Shadowsocks 2022
final, and Start Layer Off on every member. Between the first imported stream
and the final, distinct imported and independently paired Shadowsocks streams
can now appear repeatedly in their original order. Compare must actually have
selected Local before a private-response offer can be measured or adopted.

Each operation retains its complete source, original native owner, trial and
positive selection epoch. Every private intermediate keeps its own companion
identity and credentials. Every imported intermediate keeps its public source
and measurement role. The server descriptor independently verifies the full
private identity inventory; an earlier accepted intermediate cannot lend its
identity to another position.

An eligible earlier position can measure and insert another candidate before,
between, or after retained private streams. Use in draft preserves the complete
prefix, suffix and original final. It writes no connection profile and does not
start an ordinary connection. Named Save remains separate; its penultimate
offer still replaces the final rather than silently changing the meaning of
Use. The following measurement captures the changed draft and requires a new
owner and new responses. A consumed measurement cannot certify another hop.

Insertion remains bounded by the original 96-position source capacity. A full
96-position path can retain its independently qualified penultimate named
replacement, but cannot insert a 97th member. This is a structural capacity,
not a claim of traffic through 96 installed devices. The three-member legacy
family retains its original behavior. Server-winning trials retain their
separate packet-prefix measurement capability and do not publish Local private
response scores.

The controller fixture now gives each paired test profile a domain-derived
cipher key. Its earlier repeated-byte fixture key collided with an imported
member at depth 16. The production compiler correctly refused that collision;
the independence rule remains unchanged.

## Native editor continuation

After successful Use and the original native DOWN acknowledgement, Windows,
macOS, Linux and Android start the next qualified candidate operation at the
inserted position. iOS already scheduled that next position. A retained suffix
no longer causes reopening the general picker to jump to the end of the route.

Each client recaptures the current complete draft and its linked sources before
the new measurement. Native editor lifetime, revision, selected position and
Home ownership remain part of admission. A changed or closed editor, replaced
source, unjoined previous chooser, or full source capacity suppresses automatic
continuation. The user still chooses whether to insert another measured result;
there is no automatic selection of a candidate, persistent Save, or Connect.

Android schedules that continuation only after the previous preparation has
closed its network and released its process-wide owner. Its deferred callback
then checks the same visible editor, revision, idle Home and current ownership
again. A duplicate, detached or stale callback cannot start a second operation.
Windows also rechecks the selected row and visible editor after the old chooser
returns, so a changed selection cannot adopt or continue the earlier request.

## Android location accessibility

The custom globe now exposes a labeled native accessibility click action for
Locate me, Cancel location request and Hide my location. Keyboard and assistive
activation use the same explicit permission, fresh-fix and retirement lifecycle
as the visible location control. Focusing the globe, selecting a node, touching
empty map space, or cancelling a touch does not request location. A late fix
from a retired listener cannot restore a hidden marker.

## Setup Center retention across clock corrections

The package lease begins once, at READY, and expires after 1,800 elapsed seconds.
Retry admission, the displayed countdown, delivery completion and the background
reaper now use that same fixed elapsed-time deadline. Linux boot time includes
suspend; platforms without that clock use a monotonic clock. The original UTC
`retained_until` remains a fixed public receipt rather than a renewed lease.

The original defect was reproduced with the production manager and owned files:
a two-hour backward civil-clock correction reported 9,000 seconds remaining,
while a two-hour forward correction deleted the newly ready workspace. Both
corrections now preserve the original elapsed lease. Repeat downloads and
interrupted transfers do not renew it. Explicit Delete, cancellation, shutdown,
owned-writer cleanup and cleanup-pending retries retain their existing meaning.

## AWG2 Fast and Strong entry support

Compare Local now accepts the original paired WireGuard, AWG2 Fast, or AWG2
Strong entry for authenticated stream-prefix candidates. All three preserve the
literal-address first import, independent paired or imported stream interiors,
paired final, and Off Start Layer at every position. The three-node source can
grow into a recursive draft. The original 96-node physical limit still applies.
The native diagnostic inventories 48 WireGuard and 28 AWG cases. Its AWG
cases require real client and peer parameter readback, 50 authenticated
responses for each successful choice, and reloaded DNS and application traffic.
The diagnostic also checks that changing the packet key or handshake header
reaches the original encrypted peer and yields no decrypted connection.

## Remaining implementation and acceptance boundaries

The following describes this record's original source generation. The later
[external-final and Server response continuation](IMPLEMENTATION-2026-11-25-EXTERNAL-FINAL-AND-SERVER-RESPONSES.md)
implements separately qualified families for both gaps and records their
remaining restrictions and native acceptance requirements.

The following source restrictions remain explicit; they are not described as
finished merely because unavailable paths fail closed:

- Authenticated stream-prefix candidate responses for an explicit Server or
  Compare Server winner need their own original remote measurement owner.
- Ordered paths of three or more members still require a paired final. Direct
  and pair external-exit support does not establish an imported final in those
  longer ordered paths.

The exact-source Build-all workflow remains responsible for release assets,
ARM64 server images, manifests and generated Compose. Full native platform
results, legitimate iOS provisioning, installed route/DNS/leak checks, off-LAN
operation, visual/accessibility acceptance, live private integrations and a
deliberate production deployment remain separate requirements. No new release
or whole-project completion is inferred from the local results above.
