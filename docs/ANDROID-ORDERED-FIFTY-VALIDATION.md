## Behavior

Performance → Ordered path: Fifty / Retest per node opens the exact connected ordered inventory. Each row displays its human profile name, native profile ID, position and selected transport. The view explains that private authenticated Router HTTP response timing includes connection establishment; public middle-hop HTTPS response timing begins after DNS, TCP and TLS preparation. Neither interval is ICMP ping or an individual inter-server link. The existing direct TCP rankings, external-final benchmarks and throughput renderer remain separate.

`AndroidNodeChainSession` retains the returned facade. `LayeredVpnService` lends its existing measurement service and captures the exact original plan, server, service, native session directory, source/config hashes, member, Home session/path generation, physical-network identity and MTU proof observation. The worker first retains the immutable target/Home selection and acquires `AndroidMTUMeasurementGate`. It waits for existing MTU work to join before attaching the strict typed native facade, and rechecks cancellation before Start. Cancelled, stale or failed MTU waits acquire no facade. The gate remains held through original operation drain, facade Close and durable adoption. It uses the existing 100-second operation bound. A failed drain or Close retains that exact facade and MTU lease for retry. A throwing Start is cleaned up by the original facade, even if Start did not return admission. View dismissal or Activity backgrounding cancels the request without closing host throughput. Service retirement joins the facade before closing the original measurement service and Box. Authorized MTU continuation keeps the same host measurement service; a subsequent benchmark takes a fresh MTU observation.

The separate private file `ordered-node-fifty-v1.json` stores validated native receipts, bounded to 128 records and 1 MiB. Keys include source/config hashes, position, native node ID, kind and measurement meaning. Receipts require 50 successful samples, no failures, coherent finite statistics, exact source/member/request binding, matching final native status and saved result, and original worker drain. Native generation is retained only as its hashed receipt. Closed native label forms and exact field inventories reject extra addresses, tokens and arbitrary labels. Human names remain display data and are not added to the persisted native payload.

The service/Home/request guards remain held around atomic private-file publication and exact readback. A failed, cancelled, stale, incomplete or superseded adoption retains the prior valid receipt. Rollback touches only the exact bytes written by that transaction; it never overwrites another writer's replacement. Loaded receipts remain visibly historical and do not authorize readiness, reconnection, candidate adoption or rankings across paths/metric kinds. Queued UI delivery rechecks its original owner and view generation.
