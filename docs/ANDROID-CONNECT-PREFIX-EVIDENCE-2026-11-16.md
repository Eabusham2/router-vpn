# Android complete CONNECT Server/Compare paths

Recorded November 16, 2026 UTC. This addresses the original ordered external
node/hop requirements and preserves the requirement authority in
[REQUIREMENTS-RECONCILED.md](REQUIREMENTS-RECONCILED.md). It extends Android's
shipping host adoption of the already-published complete CONNECT compiler.
Source, host lifecycle, encrypted networking, packaging and physical-device
acceptance remain separate evidence.

## Shipping behavior

The actual Android ordered editor, private selection store, typed source
capture and returned execution validation now retain three to eight original
members for HTTP/HTTPS CONNECT Server or Compare: one to six paired WG/AWG
prefixes, the penultimate imported CONNECT proxy and an independent paired
Shadowsocks 2022 final. Every paired member keeps its private identity; only
the imported member has an empty paired-identity slot. Source and configuration
readback continue to require the complete original arrays and exact typed
execution authority.

Complete profile Add, Load, Update and Delete keep the requested execution,
original node references and current private credentials. Replacement of the
proxy credentials or a later paired prefix invalidates the older capture.
Neither saving nor deleting a complete profile copies credentials into profile
rows or deletes the referenced private nodes.

CONNECT Server/Compare still requires the original final node's Start Layer
to be Off. The editor, transactional source preview and typed launch capture
enforce that actual native boundary. Local CONNECT keeps its existing layer
behavior. The separately typed SOCKS execution retains its current exact
three-member bound; the earlier four-to-eight-node Shadowsocks hostname path
and saved Custom TCP resolver rules are preserved. These boundaries do not
close the remaining requested graph and layer combinations.
