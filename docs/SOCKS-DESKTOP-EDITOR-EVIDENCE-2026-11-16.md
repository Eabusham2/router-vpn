## Captured choices and source ownership

All three frontends select `ordered_socks_trio_executions` for the remote execution choice and require the original middle's Boolean `ordered_socks_execution_middle_supported` hint. The ordinary Local, Shadowsocks and CONNECT capabilities cannot substitute for this typed capability. Wrong types, noncanonical strings, changed protocols, missing or duplicated sources, relinked tokens and unsupported graph lengths remain refused.

Only complete ordered node references, the execution choice, selected final identity and original profile tokens cross the connection boundary. Private credentials remain in the original node store and typed backend capture. The frontends cannot manufacture native ownership or bypass the parent compiler/proofs. Complete profile Add/Load/Update continues through the existing captured source and response guards.
