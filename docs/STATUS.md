# Implementation status

This compatibility page intentionally points to the maintained status document:

```text
docs/CURRENT-STATUS.md
```

Use `docs/CURRENT-GUIDE.md` for setup and the current logical-mode model.

Do not infer current readiness from older copied checklists. In particular, Rosenpass server/runtime integration is already part of the validated server path, while Android `VpnService`, iOS native Packet Tunnel engines, Windows native full-device TUN/DNS integration, multihop, and strict kill-switch networking remain separate incomplete capabilities.
