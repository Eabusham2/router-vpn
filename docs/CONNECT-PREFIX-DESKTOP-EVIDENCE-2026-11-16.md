# Desktop CONNECT packet-prefix execution evidence

## Delivered source behavior

The desktop controller and Windows, GTK, and macOS ordered-node editors now
admit Server and Compare both for one through six original paired WG/AWG
packet members followed by a literal HTTP or HTTPS CONNECT member and a
paired SS2022 final member. The complete graph therefore contains three
through eight nodes. The CONNECT member is always penultimate; final-node
preferences and credentials are captured from the actual last member.

Every packet-prefix member retains its original node identity, credentials,
proof, source fingerprint, and canonical Off/AES-256-GCM/whitening selection.
The CONNECT and final SS layers remain Off for this admitted composition.
The typed CONNECT preparation and source owner are preserved through native
preparation, public connection, and transactional profile save/load/update.
The existing `ordered_connect_trio_executions` capability spelling is retained
for wire compatibility; its typed source validation now checks the complete
bounded prefix. SOCKS remains governed by its separate composition checks.

This closes the desktop product/editor admission gap above the already
published shared CONNECT prefix compiler. It does not claim that every other
transport composition, mobile editor, or physical device is accepted.

The unit is published on top of the latest normal `main` ancestry. Subsequent
upstream Android fixture, installed SOCKS acceptance, imported-SS hostname
DNS, and test-partition changes are preserved. The local controller receipt
retains its actual baseline rather than being relabeled as a later combined
source build. The hostname-DNS production delta was reviewed and changes the
separate schema-2 imported-SS paths, not this typed CONNECT family-4 path.

controls. Their eventual hosted results, all other exact-SHA native builds,
release publication, private deployment, and physical-device networking are
separate evidence. None is inferred from the model and controller results
recorded here.
