# Ordinary candidate reservation ownership

The ordinary connected-candidate factory now returns an exact reservation before calling the catalog or constructing a measurement service. Android and Apple store that handle before invoking its one-shot `Prepare` method. A failed preparation is cleaned up through that retained handle. The removed owner/position/inventory cleanup export can no longer close an existing or replacement reservation with matching values.

`Close` joins admitted preparation before draining the service and catalog. A failed join retains the original handle and slot. Duplicate construction, copied owners or handles, foreign slots, and stale handles from an earlier reservation cannot borrow cleanup authority. The existing cancellation, MTU exclusion, and native retirement boundaries remain required. This unit adds no execution-entry or remote-prefix admission.
