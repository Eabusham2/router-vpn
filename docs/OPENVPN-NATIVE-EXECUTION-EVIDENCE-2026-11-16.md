## Behavior

The engine captures construction ownership before any endpoint starts. An
independently authenticated Server candidate does not require the unused Local
provider to connect. A Local observation must read the original endpoint's
connected generation, time, remote tuple and capacity. Once pinned, a different
observation or a later pending state is rejected.

Public-path measurements use a dedicated typed dispatcher. Server measurements
travel through the original authenticated Server front; Local measurements
retain the selected resolver and original OpenVPN endpoint. Generic imported
measurement admission remains closed to this family. Saved Last preparation
keeps authenticated discovery and the same native owner. MTU reader changes keep
the original OpenVPN construction and captured connected receipt.

Restoration's retirement observer requires the original retired engine, closed
and drained application gate, and the captured Box close receipt joined against
that exact Box. An early done channel or another equal-content source cannot
replace completed original retirement.

The concrete OpenVPN import lives behind `with_openvpn`. The actual mobile
build without that tag compiles its refusing stub. Both mobile packaging paths
run the new positive, stub and compiled omission gate. Desktop runs the tagged
gate, because its additional endpoint fixtures require the shipped OpenVPN
implementation. Existing mandatory gates remain in place.

Both new validation scripts participate in the mobile and desktop cache input
closures. A validation-script-only change therefore invalidates reused runtime
evidence.
