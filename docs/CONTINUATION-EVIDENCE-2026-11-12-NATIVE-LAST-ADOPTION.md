# Native adoption of the saved ordered execution choice

## Scope

This unit connects the existing opaque shared Last plan to the original native execution engine. It does not enable Apple or desktop Server/Compare admission and does not claim physical TUN, encrypted-path, Apple SDK, signing or device acceptance.

A durable Last record is source-bound data, not live proof or cleanup authority. The native engine must perform fresh authenticated discovery with its original Box before it can admit the saved choice. `AdoptLastContext` uses that exact discovery owner to construct the shared plan, retains the plan and canonical Last record before closing discovery or changing the native graph, and uses the existing selector/application-gate adoption transaction. It preserves the original Box, inbound reader and graph. The shared Last runtime still must perform its real Run before becoming healthy.

A failed join retains the original plan. A retry cannot change the saved choice or discovery owner, and ordinary adoption cannot consume the occupied Last slot. Canceled callers cannot replace the retained plan. The existing live restoration path remains separate: it preserves the previously proved complete frontend through `AdoptOriginalContext` and requires the original native close receipt.
