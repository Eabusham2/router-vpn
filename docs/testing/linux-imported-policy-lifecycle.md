# Linux imported WireGuard entry and paired Shadowsocks lifecycle

This unit adds the sealed compiler and retained native preparation for one
protected Local pair: an independently imported WireGuard entry and a paired
Router VPN Shadowsocks final, with both Start Layers off. Other Linux imported
pairs and layers remain rejected by this compiler boundary.

The policy retains the original imported controller. The derived source binds
the target, session, complete entry/final configuration, independent identities,
selected final DNS, both proof listeners, physical entry tuples and restored MTU.
It cannot be substituted for an ordinary NodeProfile. Linux and Windows source
identities differ even when they describe the same original pair and session.

The Linux native adapter shares the existing source admission and retirement
coordinator through the sealed physical-policy interface. It retains the actual
interface capture, exact socket broker, nftables baseline, guardian, original
parent callbacks and joined protection owner. An imported Box has its own typed
preparation and activation owner. Selected DNS is proved through that original
Box before activation returns. Public imported command and application admission
remain closed on Linux pending the authenticated parent integration and both
proofs. This prerequisite does not claim a usable protected Linux UI path.

## Required checks

- `TestDesktopImportedPolicyLinuxCapturedPair` checks complete graph derivation,
  physical entry ownership, selected final DNS, target binding and rejection of
  unintegrated entry/final/layer choices.
- `TestRouterVPNNodeLinuxLifecycleImportedCapturedPair` executes the generated
  compiler, native lower, interface capture, broker and lifecycle coordinator.
  Its privileged source constructor is modeled. Both on-connect and always
  policies run live, refused baseline, foreign compiler, refused admission,
  cancellation, changed baseline, partial construction and failed join cases.
- The existing desktop physical factory runner requires the test root and all
  sixteen leaves. The runner contract rejects missing, skipped and duplicate
  verdicts. These are part of the existing native source gate, not a separate
  optional workflow.

A sandbox that denies network-interface netlink reads cannot execute the strict
native fixture. A separate diagnostic interface model can check the remaining
coordinator logic, but does not replace a passing unmodified native-host run.
Kernel packet traffic, inherited-controller authentication, entry public proof,
paired-final authenticated proof, selected-DNS publication, cancellation,
restoration, MTU ownership and successor retirement require their full Linux
host integration before public admission is enabled.

## Observed local evidence

The shared imported-policy race selection passed in 29.253 seconds. The actual
pinned native desktop package and the generated Box package compiled. The
unmodified sixteen-case native fixture stopped at the environment's denied
`net.Interfaces` Netlink operation before its constructor; that is not a native
runtime pass.

A separate diagnostic-only copied-core overlay modeled interface enumeration
and readback. The final-source sixteen imported lifecycle cases passed under
race detection in 8.940 seconds; the existing and imported Linux lifecycle
regression selection passed in 27.370 seconds. The privileged constructor was
already an explicit fixture boundary. Neither interface overlay nor a test skip
was added to the repository. The existing Box prepared-owner check passed with
no interface overlay; it is not an imported end-to-end connection test.

The retained native constructor's exact nil/partial return boundary passed two
extracted race cases. Removing its nil-preservation check made the causal
control fail because a nil pointer became a retained nonnil interface. The
temporary harness was removed. Existing routing-runner checks and the exact
seventeen-verdict imported inventory controls passed; missing, skipped and
duplicate native results remain rejected.
