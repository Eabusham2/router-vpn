# Hysteria2 Server native acceptance — November 16, 2026

This unit adds a mandatory actual Server-suffix gate for the original paired
schema-1 Hysteria2 graph. It preserves the shipping worker, source and capture
identity, private proof inventory, selected final DNS, authenticated front,
and strict Stop/worker/peer joins. No production admission or timeout is
weakened. Hysteria2 remains the final Off-layer node; each preceding packet
node retains its independently captured Off, AES or AES+XOR layer.

## Exact topology boundary

The captured entry belongs to the client/lease side of the complete product
graph. The Server worker executes the suffix after that entry. The native
acceptance fixture captures the original entry identity but does not run a
second entry endpoint or infer an entry lease from the suffix proof.

| Complete captured graph | Remote packet prefixes exercised by this gate | Actual suffix |
| --- | ---: | --- |
| 2 nodes | 0 | Hysteria2 final |
| 3 nodes | 1 | Original WG/AWG prefix, then Hysteria2 |
| 8 nodes | 6 | Six independently captured WG/AWG prefixes, then Hysteria2 |

The eight-node boundary therefore retains seven paired packet-node assets in
the complete graph: the captured entry plus six remote prefixes. It does not
inherit the smaller OpenVPN family limit. Intermediate total lengths four
through seven remain covered by the separate complete source/consumer matrix;
they are not counted as executed native lengths by this unit.

The mixed six-prefix layer order is AES, AES+XOR, Off, AES+XOR, AES, Off.
The original concrete SS2022 and whitening layer owners decrypt and forward
only the captured private WG/AWG tuple. Each layer receipt retains its mode,
outer endpoint, inner endpoint, private destination and independent raw,
authenticated, forwarded and rejected counters. A failed first layer must
record rejection without delivering a WG packet or reaching Hysteria2.

The actual Hysteria2 provider retains QUIC/TLS, its private CA and SNI,
password and Salamander mask. Direct mode uses a test-owned public /32 inside
the isolated peer namespace and requires the unused WG reference counters to
remain zero. Positive cases require private identity proofs, public HTTPS,
selected final DNS and TCP/UDP delivery. Wrong authentication, trust or keys
cannot produce inner application traffic. Stop must join the original worker
and peer and make the retained active UDP flow unusable.
