# Multiple imported execution, restoration and measurement ownership

This unit connects the existing schema-six Server plan and relay foundation to the shared client execution state machine. It retains the complete original Local source for a paired WG/AWG entry, independent literal SS2022 interior imports at their original positions, remaining paired packet interiors, and a paired Shadowsocks final. The selected execution can be Server or Compare. Existing schema-one through schema-five admission, digest and singleton contracts remain unchanged.

## Implemented behavior

The distinct preparation requires the original typed import registry and its exact sealed launch. Mobile preparation has four fields: schema, execution, local source and multiple-imported Local launch. Cross-family fields, copied owners, missing imports, changed source and changed projection are refused. Discovery still authenticates the original descriptor and challenge. Each public import retains its own source digest, actual position and expected public IP; no imported node receives a fabricated private Router API identity.

The shared runtime admits Local and independently provisioned Server candidates through the original execution manager. It requires an explicit native observer for the original Box and imported transport owners. Proof inventory uses the selected path's actual tags while retaining the complete original source and all public positions. Compare retains the existing two-response average, a common external endpoint, repeated winner proofs, cancellation, and original operation deadline. An unavailable or invalid candidate does not receive a score.

Joined restore and Last discovery preserve the selected execution, complete source, original owner and issued interface readback. Restoring a proved Server choice does not rerun Compare. Mobile restore carries an owned capsule; identical JSON cannot reconstruct that authority. Desktop physical handoff, adoption and Ready records have a distinct schema-six family and retain the complete original import inventory.

Selected fifty-sample capture adds an optional `multiple_imported` object containing schema 6, the complete original source hash, and ordered public position/tag/source-hash records. The six-field legacy capture is unchanged. Server hop measurement uses each selected original public prefix and checks complete TLS responses, ownership, cancellation and freshness before publishing results.

## Failures corrected without changing production deadlines

The first larger Compare fixture exceeded its existing 20-second operation deadline. Profiling found repeated full graph traversal in imported-policy capture checks. The separately published `6ce93a724b3fd7e4953d0e00a662d646ef9bfce3` retains the original validated policy and seal while still checking its complete current source/config/metadata/private-capture seal on every observation. It does not cache successful network proofs or alter timeout values. The maximum public-import Compare fixture then completed in 14.19 seconds.

The first ownership-refusal run exposed a test race: fixture cleanup rewrote the running preparation while an owned stop operation read it. The corrected test creates detached copies for copy/substitution cases and first proves the detached binding valid before removing its owner. It restores only its idle borrowed measurement projection before closing the measurement. Original runtime-owner loss and synchronized selected-epoch cancellation remain separately checked. No production synchronization, validation or rejection case was removed.

## Evidence boundary and remaining integration

These tests execute the real shared execution manager, authenticated private HTTP, verified public TLS, complete discovery/restore validators and fifty-sample measurement logic. Native transport, route, DNS and interface callbacks in these shared fixtures are controlled doubles. Linux, Windows and Darwin names identify distinct handoff contracts executed on this Linux test host; they are not native operating-system or device acceptance.

Actual Box/worker schema-six dispatch, encrypted provider/namespace traffic, desktop process factories, Android and Apple host adoption, public UI capability, and selected-capture consumers remain separate integration units. This commit does not advertise those unfinished hosts as available or establish a green release, deployment, signing or physical-device acceptance.
