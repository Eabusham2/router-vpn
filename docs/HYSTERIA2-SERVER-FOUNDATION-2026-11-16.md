## Preserved source and policy

The supported source is the original schema-1 paired chain with two through
eight total nodes. Preceding nodes retain WireGuard or AmneziaWG and their
independent Off, AES or AES+XOR Start Layers. The Hysteria2 final retains its
original Off Start Layer, literal endpoint, private TLS trust, server name,
password and Salamander configuration. Existing imported-middle families keep
their separate final-node contracts.

Server planning still requires an independently provisioned WireGuard identity
asset for each paired member, including the proxy final. The complete Hysteria2
transport must match between the independently provisioned bundles. A changed
password, endpoint, TLS name or trust, obfuscation, DNS policy, node identity or
identity key cannot substitute for the captured source.

The server suffix adds no TUN or listener during compilation. Its final proof
retains the original private node identity, and its selected Home AdGuard policy
stays on that final path. The authenticated client front keeps its original
UDP-over-TCP transport declaration. No Hysteria2 packet keys are invented.
Local and Server candidates retain the same source, closed application gate,
proof inventory and DNS policy. Restoring a proved choice retains that choice;
Last restoration freshly proves the original captured winner.

## Remaining acceptance

This unit does not enable a public host by weakening its capability guard.
The real native Server worker must still establish the captured Hysteria2
provider, prove its selected DNS and exact final identity, move actual TCP/UDP
traffic, reject wrong credentials/trust and join all owned resources. Native
host/controller and editor adoption, exact-SHA packaged builds and publication,
physical-device networking and private deployment remain separate evidence.
Encrypted Hysteria2 final Start Layers and other graph families remain outside
this bounded source change; their original requirements are not discarded.
