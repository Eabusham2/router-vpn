# Desktop OpenVPN execution records — November 16, 2026

This prerequisite supplies the private adoption and readiness records used by
the desktop OpenVPN Server/Compare integration. It continues the captured
session and Local/Server requirements in the reconciled ledger. It does not
by itself publish a desktop host integration or prove a connected device.

## Record ownership

The adoption parser reconstructs the schema-five execution policy from the
parent's original preparation. The child record carries its typed Server
descriptor and request, transfer identity, projected engine/network/session
identity, and captured physical-source digest. It does not repeat the Local
source or replace the parent's captured private settings.

The readiness parser requires canonical bounded JSON, the same preparation
and transfer, selected epoch, proof generation, reader, interface and MTU,
the selected DNS capture, and complete per-member proof results. It preserves
the required average of the last-node and external response times. A failed
candidate must have a failure reason and no score. The desktop parent must
also retain the actual child and independently check freshness and native
interface readback; a record alone grants no process, route, TUN or lease.

The imported OpenVPN member's completed HTTPS proof now explicitly reports
`public-path` and the existing cumulative-path label. Private Router proof
rows retain their existing presentation. This prevents a public provider
measurement from being presented as a private Router-agent response.
