### Protected Windows SOCKS5

The admitted scope is direct Local, Start Layer Off, and On-connect/Always.
The application, captured policy, generated command, Box and native association
host agree on this scope. A per-operation native SOCKS client retains its own
authenticated TCP control and exact negotiated numeric UDP relay. A relay does
not become a global permission for other operations. Original credentials,
selected DNS, MTU, protection, original/derived source identity, measurement
operation and Router restoration remain captured. Server/Compare, predecessors,
Start Layers and unsupported platform combinations retain their requirements.

The normally prepared pinned runtime executed six association factory cases,
twenty-two required Box cases and the exact-authority command cases on Linux.

proof, MTU rollback, all fifty response-time samples, wrong credentials/trust/
resolver/exit, invalid relays, control EOF, cancellation and independent owners.
The OS admission and packet-pump fixture boundaries remain explicit.

### macOS installation and PF ownership

The first/legacy installer previously attempted a bare host inventory, which
rejected an unrelated unlinked executable without comparing it to product
ownership. Admission now captures the complete current protected installation
and verified incoming stage. An ephemeral legacy observation never invents a
historical receipt. Both linked renamed and unlinked copies are compared using
the existing kernel image identity, with process/exec/path fences. Unknown
identity, incomplete present code and changed recorded generations still fail.

The incoming Go bootstrap was found to remain alive during that image scan.
The final shipping fix exec-replaces it with the already validated interpreter;
the fixed Python supervisor runs the captured installer in the same PID and
owns cleanup of that exact private directory. Same-PID execution, real argument
failure status, streams, failed exec, replaced-directory refusal and cleanup
were tested. No PID, signer or unrelated-process exception was introduced.
[The ownership boundary](MACOS-INSTALLER-LIVE-IMAGE.md) records what an erased,
unregistered historical image cannot establish.

The PF change addresses an observed serial tail in Intel macOS readback.
Independent direct/recursive filter and NAT queries share at most four actual
native command slots, including nested groups. Slots are held through command
join; waiting parents do not hold one. Earlier nonempty owners, stateful or
unknown filters and NAT/RDR/BINAT remain refusals. The original two-second
grant deadline, complete joins and prohibition on changing foreign rules remain.
