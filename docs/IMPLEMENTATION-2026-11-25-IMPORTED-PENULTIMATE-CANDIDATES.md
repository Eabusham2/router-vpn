## Implemented route and operation

The original schema-six source has one paired WireGuard entry, independently
captured literal-address Shadowsocks 2022 interior imports, zero or one paired
private Shadowsocks 2022 interior, and one paired Shadowsocks 2022 final. Every
Start Layer is Off. The first interior is always imported; any private interior
occurs after it. The source and UI capacity is four through 96 members.

The penultimate member can now be imported, with either no private interior or
an earlier private interior. A paired private penultimate member retains its
previous behavior. The requested execution remains Compare (`auto`); the
authenticated private-response operation requires the original healthy Local
winner and its original positive selection epoch. It does not start another
Local graph or rerun Compare. Server selection cannot produce a private
candidate score or a saveable result.

The candidate must be a distinct paired Shadowsocks 2022 node. Every original
profile and private proof identity, including the old final, remains excluded.
The operation measures 50 authenticated private agent responses through the
original retained penultimate prefix. TCP connection establishment, a direct
probe or a public response cannot stand in for that measurement.

An explicit named Save creates a separate complete profile that replaces only
the final member. Its requested Compare setting and every original prefix
member remain intact. Explicit Load is required to adopt the named route.
Measurement and Save preserve the current Home profile and active connection.

## Controller and client ownership

The existing `response_source_nodes` field retains every original public
`id`, `mode` and `kind`, in order. Catalog, result, Save and cancellation retain
that same map and view token. A connected result also retains its selected
Local winner and positive epoch. The map is a description of the captured
source; it grants no measurement authority.

Connected cancellation before admission reserves the request identity against
its original issued view, even if another window has refreshed the catalog.
Missing or crossed views cannot cancel a mapped operation. Original retries
retain the joined cleanup boundary and return no candidate scores. A draft
cancelled before startup retains its source and required Local selection but
does not invent a selected winner, selection epoch or native DOWN receipt.

The shared runtime, desktop controller, Windows, GTK, AppKit, Android and iOS
must agree on this same source family and sole eligible stream position. The
complete source compiler, original native owner, original imported registry,
candidate inventory, retained selection epoch and joined cleanup remain
required independently of the public role map.

at an earlier imported position. The selected mobile capture currently seals
one response position; extending it needs a separately captured per-operation
position, exact insertion action, full suffix identity exclusion and independent
native qualification. Existing ordinary Local intermediate-profile behavior
retains its existing scope.

hop, hostname resolution, an AWG entry, another transport or an enabled Start
Layer to this selected response operation. Ninety-six rows are a source/UI
capacity, not a claim of native or installed acceptance at that depth. The
required separate-process worker gate, exact-SHA release packages, legitimate
iOS provisioning, physical-device traffic and private/off-LAN deployment remain
independent acceptance requirements.
