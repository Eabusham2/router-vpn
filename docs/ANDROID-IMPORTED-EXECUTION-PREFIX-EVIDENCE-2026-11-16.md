## Evidence boundary

Native Run, remote leases, proof, TUN and live restoration are explicit refusing
boundaries in this source gate. Generated bindings, actual encrypted Server
traffic, APK provenance, publication and physical Android networking require
their own evidence. Permission, selected-path DNS, leaks, transitions, visual
checks, signing and upgrade acceptance are not established by this matrix.

Multiple imports, other imported positions, longer typed SOCKS/CONNECT execution
and other requested graph families remain separately accountable. Safe refusal
does not close those requirements or establish full-product delivery.
