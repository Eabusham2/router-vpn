# Ordinary Local multiple-import core: November 16, 2026

Schema6 retains one or more independently imported Shadowsocks providers at
their original interior positions in a three-to-eight-member Local chain. The
paired WG/AWG entry owns physical egress; remaining paired packet members keep
their original sources; the paired Shadowsocks final owns application DNS and
its independent Off, AES or AES+XOR layer. Imported providers retain separate
credentials, literal addresses, expected public IPs and proof positions.

The compiler, runtime, ordinary native Box, desktop physical bootstrap policy
and hopmeasure code now preserve this complete source. Public measurement uses
the captured position/tag/source tuple for each imported member, with a fresh
complete-source validation and the exact original source pointer. Nested packet
MTU arithmetic includes intervening imported closures, adjusts only the compiled
Auto capacity and retains fixed-MTU refusals and original source values.

This is the shared/native core slice. Schema6 Server/Compare, typed SOCKS/CONNECT,
imported hostnames and measurements through arbitrary non-packet candidate
prefixes remain closed. Mobile and desktop UI consumers are separate units.
Nothing here substitutes ordinary reachability for the candidate feature's
50 routed TCP-handshake samples.
