# Desktop CONNECT final Start Layers

The Windows, Linux and macOS ordered-path editors, saved connection profiles
and desktop CONNECT capture now preserve an independently selected Off,
AES-256-GCM or AES-256-GCM plus XOR whitening layer on the paired final node of
a Server/Compare HTTP or HTTPS CONNECT path. The imported CONNECT member
retains its original Off policy. The final's original private source, credentials,
typed shared compiler and exact UoT-v2 service remain required.

This change consumes the shared/native owner implementation published in
`e31d7d20d5862ecd86c3a3807ce752889d7138d8`. It removes the obsolete final-Off
consumer restrictions, while retaining canonical layer validation, complete
node references, transactional profile behavior, owned cancellation and the
already-proved Local/Server choice during Last restoration. Invalid XOR-only,
unknown and incorrectly typed selections remain rejected.

## Local compiler and display limits

Two attempted full-package Go test compiles terminated with SIGKILL before any
test result. They are retained as failed attempts, not passes. The successful
local fallback kept every shipping production file selected by Go and 110
original test files containing the target cases, their conservative dependency
closure and existing test initializers. It overlaid only 454 unselected test
files with an empty package declaration. The causal controls additionally
overlaid their one original production guard. Every one of the 31 expected test
records remained mandatory. The complete-package native CI compile and gate
are unchanged and remain required for platform acceptance.

The full Linux GTK widget run could not start its owned Xvfb display because
the environment refused its listening sockets. Its full widget result remains
unproved locally. The existing model-only path passed; it is not reported as
GTK visual acceptance. The Windows process was started with the documented
PowerShell telemetry opt-out and update checks disabled after an initial
automatic-review block on telemetry. No network exception was added.
