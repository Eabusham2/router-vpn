This unit connects the shared multiple-import Local source to the desktop
controller. Three through eight original members retain a paired WG/AWG entry,
independent literal Shadowsocks providers at any interior positions, paired
packet members where selected, and a paired Shadowsocks final. The controller
captures each private/imported source before preparing its native graph.

Complete connection profiles, startup Last and per-hop measurement retain the
same ordered member references, original settings and source fingerprints.
Every imported position has its own public measurement row. Catalog capability
is a strict presentation hint derived from the supported original import;
Connect and restoration still validate the complete actual source. The change
contributes to the original external-node, profile, per-hop and restoration
requirements. Desktop visual editors and other graph/execution families remain
separate units.
