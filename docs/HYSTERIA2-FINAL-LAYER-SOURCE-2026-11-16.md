# Captured Hysteria2 final Start Layers: shared source boundary

This unit permits an independently captured AES or AES+XOR Start Layer on the
paired Hysteria2 final of a two-to-eight-node ordered graph. Every preceding
node remains an original WG/AWG packet source. Imported graph families retain
an SS final, and Hysteria2 does not become a TCP candidate-measurement source.

The final closure compares both complete native objects with the original sealed
single-node configuration before namespacing them. TLS name and CA, Hysteria2
password and mask, inner destination, outer cipher/key/destination and the
original selected DNS remain captured. The composer routes only the outer layer
through the preceding packet prefix. A Server suffix containing just the final
keeps that outer layer as its physical transport. Server plans retain independent
provider identity credentials; this unit creates no new credential substitution.

This is a shared source/runtime foundation. It does not establish encrypted
native traffic, installed-host acceptance, physical-device acceptance or current
release CI. The corresponding native provider/worker and public consumer gates
must pass before the complete feature is considered delivered. The accompanying
[Apple consumer unit](APPLE-HYSTERIA2-FINAL-LAYERS-2026-11-16.md) aligns its actual
source, identity, map, Local selection and editor tests in the same publication.
At this snapshot, desktop and Android public final-layer adoption and native
acceptance remain separate units; their completion is not inferred here.
