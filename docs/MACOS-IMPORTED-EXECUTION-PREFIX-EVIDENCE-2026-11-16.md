# macOS complete imported Shadowsocks execution

## Scope and shipping path

This change closes the remaining AppKit and Darwin admission restriction for
three-to-eight-member imported Shadowsocks Server/Compare paths. Each path
retains one to six paired WireGuard/AWG prefixes, one literal-address imported
Shadowsocks 2022 member, and an independently paired Shadowsocks final. The
original request remains the full requirement set in REQUIREMENTS-RECONCILED.md;
this evidence covers this particular source and UI integration.

`RouterVPNConnectionProfiles.swift` checks every original catalog member in
the ordered draft and Connect request. Every paired member must retain its
paired kind and canonical independent Start Layer. The imported member must be
penultimate and have the actual Boolean execution hint. Complete profile
Add/Load/Update preserves every source token, position, mode and execution.
Private credentials remain in the controller's original node store.

The existing `ordered_imported_trio_executions` capability key stays compatible
with the controller. Its historical name does not truncate the complete
Shadowsocks path. Typed CONNECT keeps its separate exact-trio capability and
admission; this change does not widen its source family.

`desktopDarwinImportedTrioExecutionMembers` now checks the complete three-to-eight
member source and every paired Start Layer. The public platform selector still
requires the existing retained native architecture and supported Darwin CPU.
The original source compiler, physical policy and Darwin parent/child ownership
remain on the shipping path. The previously published Windows/Linux fixture
now expects this supported Darwin source shape while retaining all original
preparation, identity and replacement-owner assertions.
