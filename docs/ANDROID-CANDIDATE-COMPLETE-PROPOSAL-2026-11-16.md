# Android measured next-hop proposal preservation

The original candidate plan measures a target reached through a captured packet
prefix. Its proposal now replaces **prefix position + 1** in the original complete
path. It retains all other members, their private source references and policies,
the unchanged final node's DNS, and the exact Local/Server/Compare selection. It no
longer truncates the suffix, appends an extra imported node, or silently saves Local.

The proposal checks the original admitted result and generation, exact measured
candidate source, complete member/proof identity uniqueness, and the original
captured packet position. The existing complete ordinary or typed SOCKS/CONNECT
compiler remains final admission authority. Replacing a role with an incompatible
transport, putting an imported proxy at the final position, or duplicating the
retained final identity fails before any profile write. The final source compiler
readback retains every original member and independent identity. Server/Compare
previews use their existing family-specific constructor; no new parser is opened.

Saved rows keep private node references rather than copying credentials. Existing
joined candidate/outer graph authority, expiration, fresh pre-commit checks, normal
explicit Load and source-change-away/back refusal remain active. This change creates
no native session and does not widen the current temporary prefix admission to
remote execution. The future proposal source preserves the requested execution even
when a given native candidate path remains unavailable.

library, real shared Go source constructors, and existing bounded native callback /
outer graph doubles. The metric in these tests is still fifty TCP-connect samples;
a fixture callback is not authentication, a SOCKS UDP association, CONNECT TLS,
