# Android original Hysteria2 final layers — November 16, 2026

Android's ordered Local, Server and Compare choices now retain the paired final
node's independent Off, AES-256-GCM or AES-256-GCM plus XOR whitening source.
The existing schema-1 graph still requires two through eight original paired
members, with WG/AWG packet prefixes. Imported-middle families retain their
separate Shadowsocks-final boundary. No new native factory or source schema is
introduced.

The final picker checks the exact selected node's captured member when an
authenticated layer is requested. Copying another node's Hysteria asset into a
layered bundle does not acquire this choice. Existing Off eligibility retains
its original paired/mode checks without an extra member compilation; complete
Save still invokes the original full source compiler. The remote saved-selection
guard checks the original value's type and exact spelling, including rejection
of null, non-string, unknown, alias and XOR-only values. Missing or empty values
retain the established Off convention.

Original TLS, password, CA, inner destination, outer cipher/key, whitening,
packet-prefix detour, private WG identity, selected DNS and complete profile
references remain owned by their original captures. The tests check that the
outer layer belongs to that same final node and does not substitute UoT. Last
reopens the original source and requested/selected choice; it does not repeat
Compare or claim a live native proof from a saved record.
