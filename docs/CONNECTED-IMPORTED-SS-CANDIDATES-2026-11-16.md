# Connected candidates on complete imported-SS paths

The connected candidate planner now accepts every original WG/AWG packet
position in a complete schema-2 path with one through six packet prefixes,
one independently captured SS2022 middle, and the original paired Shadowsocks
final. Previously, `NewCandidatePlan` refused these paths unless they had
exactly three members. The change removes only that count fence.

A source plan does not grant a live route. The existing measurement constructor
and every subsequent observation still require the complete original chain's
fresh Healthy/Ready state, private proofs, public proof, selected DNS, source
and configuration, engine reader, session, network and candidate catalog. An
observed owner change revokes the measurement permanently. A held connection
close retains its original measurement lease until retirement joins.

The measurement remains fifty routed destination TCP connections. It does not
authenticate the candidate's Shadowsocks credentials or measure application
throughput. The imported stream and paired final do not acquire this packet
prefix timing capability. Saved closed-prefix preparation retains its separate
source and application-closed lifetime; it cannot substitute for a ready
connected complete path.

The new peer fixture installs its one literal candidate route through the
existing original-handler decorator before any native peer device starts.
Existing callers pass no decorator and retain their original construction.
There is no mutation of a live handler's route map.

## Source identity and integration

Shared execution used private snapshot `e0659011` on published `70e6b344`.
Native execution used private `ce6cd8c1` on published `bdab0b5b`, including the
subsequent twenty-line native wrong-key assertion improvement. All shared Go
source and test bytes remained unchanged between those snapshots. Native
source was prepared from the pinned original core `1ac1a339` and Xray
`50231eaf` by `build-native-runtime.prepare_native_sources`.

Publication composition preserves newer `aa458312`, `0ff440cf` and `fc203c75`.
The source review found the connected-SS production, tests, source-owner code,
runtime and existing Box owner fixture unchanged. The actual imported-start,
captured-prefix-range and original final-provider helper functions are byte
identical. New direct paired-SS hooks and fixed-address fixture admission are
outside this component's executed branch; new typed SOCKS/CONNECT wrappers
retain their separate owners. The registry preserves both mandatory families.
The old images remain evidence for their recorded snapshots, not a claimed
fresh compile of the composed tree.

The four shared roots are mandatory disjoint core phases. All 32 native cases
are mandatory preflight cases of the existing Linux node-host TUN runner,
using its original retained peer image and source/image checks. Builder inputs
include both new runner files. The existing required SS-prefix workflow keeps
the complete 17-record Box owner inventory. No runtime or compile bound was
increased and no existing required case was removed.

The initial local native command stopped before compilation because its
verification subprocess selected an ambient `go` executable. The local driver
then installed the existing pinned environment before verification. Prepared
source was unchanged; the subsequent actual compilation and all cases passed.
That setup failure is retained separately from the native test verdicts.
