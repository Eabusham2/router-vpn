A measured candidate now replaces **captured prefix position + 1** in the original
complete ordered path. The source proposal retains every other member and private
node reference, their independent identities and Start Layers, the unchanged final
DNS policy, and the exact Local, Server, or Compare selection. It no longer truncates
the suffix, appends an imported node, or silently saves Local.

The original candidate input must equal the measured input. The proposed path must
have unique profile and paired proof identities. The existing complete ordinary or
typed SOCKS/CONNECT source compiler remains the final admission authority, including
for Server/Compare previews. An incompatible next-hop role, imported final, duplicate
identity, changed retained prefix, changed final credentials, or changed selected DNS
fails before Save. No connected candidate or native Server admission is opened.

Complete original RouterProfiles are retained for Save, including startup and
autoconnect preferences that are intentionally absent from native source projections.
The retained prefix source and independent identity strings are checked exactly.
Unchanged suffix members remain exact. The final member necessarily changes its
ordered references, so its complete sealed source is regenerated through the actual
`LibboxRouterNodeChainMemberInput` using the original mode, transport files, Start
Layer, DNS bootstrap, and profile with only those control references updated. The
entire returned member must match the new projection; no hash or identity field is
ignored or copied from the replacement source.

The shipping profile store preserves requested execution, all private references,
normal explicit Load, source/receipt freshness immediately before the atomic write,
and transactional refusal when source or policy changes. The measured receipt,
expiration, exact source, and joined ownership guards remain in their existing
callers. This is a future saved source graph, not an alteration to the live path.
