# Security

- Keep the repository private.
- Never commit generated client bundles, private keys, passwords, API tokens, or provisioning profiles.
- Do not expose ports 1080, 8786, 8787, 9443, 2053, SSH, or AdGuard administration to the WAN.
- Use the protected-DMZ feature only after the AI Board firewall guard is active.
- Rotate the generated bundle if it is copied to an untrusted device.
