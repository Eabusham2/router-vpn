# Start here

Use only **`router-vpn.zip`**.

1. Read `INSTALL-EVERYTHING.md`.
2. Install the router stack through Portainer or SSH.
3. Download the private `router-vpn-client-bundle.zip` generated by the router.
4. Install that bundle on the travel device.
5. Enter the home public IP, IPv6 address, or hostname in the app at runtime.
6. Select AUTO or a manual mode.

The router-generated bundle contains private keys and credentials. Do not upload or share it.
